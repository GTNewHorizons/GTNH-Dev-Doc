This section takes you from "I want to change something" to an open pull
request. Before you start, have a change in mind that you can describe and
check, such as a bug you can reproduce or a tooltip you want to fix.

## What you need

- A GitHub account and Git.
- For mod code: some Java experience, IntelliJ IDEA, and several gigabytes of
  free disk space for Gradle downloads, Minecraft sources, and test worlds.
- For translations, assets, pack data, or documentation: the editor and tools
  listed in the repository's README.

These guides use command-line Git. If you'd rather use a graphical client,
[Contribute with GitHub Desktop](/GTNH-Dev-Doc/contributing/contribute-with-github-desktop/)
covers the same Git steps, and the rest of each guide still applies.

## Changing mod code

<Steps>

1. [Choose a repository](/GTNH-Dev-Doc/start-here/choose-a-repository/).
   GTNH is split across many repositories. Find the one that controls the
   behavior you want to change, and read its contribution rules.
2. [Set up your workspace](/GTNH-Dev-Doc/start-here/set-up-your-workspace/).
   Fork and clone the repository, create a branch, install the right Java
   version, and open the project in IntelliJ.
3. [Build and run](/GTNH-Dev-Doc/start-here/build-and-run/).
   Build the project and start the game before you change anything, so you
   know your setup works.
4. Optional: [Make your first GT5 change](/GTNH-Dev-Doc/start-here/make-your-first-gt5-change/).
   A small practice edit to GregTech that you build and check in game.
5. [Make your first pull request](/GTNH-Dev-Doc/start-here/make-your-first-pull-request/).
   Commit your change, push it, and describe what you tested.

</Steps>

Already have a working checkout? Skip to the step you need.

## Changing translations, assets, or pack data

Choose the repository as in step 1 above, then follow
[Contribute with GitHub Desktop](/GTNH-Dev-Doc/contributing/contribute-with-github-desktop/)
to clone it, edit the files, and open a pull request. If you prefer the
command line, use the
[fork and clone steps](/GTNH-Dev-Doc/start-here/set-up-your-workspace/#fork-and-clone)
and then [Make your first pull request](/GTNH-Dev-Doc/start-here/make-your-first-pull-request/).

The repository's README tells you which editor, generators, and checks your
change needs. Documentation inside a mod or tool repository works the same way.

## Changing this documentation

Follow [Contribute to this documentation](/GTNH-Dev-Doc/contributing/contribute-to-this-documentation/).
It shows how to find a page's source file, edit it, preview the site, and
submit your change.
