Start with a change you can describe and test. These guides take you from
finding the repository that owns it to submitting a pull request.

For graphical Git, [Contribute with GitHub Desktop](/GTNH-Dev-Doc/how-to/contribute-with-github-desktop/)
walks through setup, editing files, and submitting the change. It covers code,
textures, translations, documentation, and pack data. The path below uses
command-line Git; its Java and mod-launch steps apply to mod development.

<Steps>

1. [Choose a repository](/GTNH-Dev-Doc/start-here/choose-a-repository/).
   Identify the code or data responsible for the behavior, check existing
   work, and read the contribution requirements.
2. [Set up your workspace](/GTNH-Dev-Doc/start-here/set-up-your-workspace/).
   Fork and clone the project, create a working branch, and prepare the tools
   that repository needs.
3. [Build and run](/GTNH-Dev-Doc/start-here/build-and-run/).
   For mod code, get the development environment working before editing.
   Test the relevant client, server, and pack behavior after your change.
4. [Make your first pull request](/GTNH-Dev-Doc/start-here/make-your-first-pull-request/).
   Review the diff, commit your change, and report what you tested. Use the
   same branch for revisions during review.

</Steps>

For textures, translations, documentation, or pack data, follow the chosen
repository's validation instructions.

If you already have a working checkout, go directly to the step you need.
