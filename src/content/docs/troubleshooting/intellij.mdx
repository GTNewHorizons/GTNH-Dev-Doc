:::note[Signs]
Code compiles in Gradle but appears unresolved in the editor, generated sources are missing, or navigation stops working.
:::

<Steps>

1. Wait for Gradle synchronization before judging indexing results.
2. Confirm the terminal build works with the repository-required JDK.
3. Reload the Gradle project so source sets and generated directories come from
   the build model.
4. Check whether generation is performed by a documented Gradle task.
5. Invalidate IntelliJ caches only after confirming the Gradle model and build.

</Steps>

For an older repository that exposes `setupDecompWorkspace`, delete its
generated `build` directory, run `./gradlew setupDecompWorkspace`, and reload
Gradle. Do this only when that task exists; current GTNHGradle projects should
use their existing build and IDE-generation tasks instead.
